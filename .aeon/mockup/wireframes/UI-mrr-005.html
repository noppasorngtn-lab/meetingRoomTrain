ปฏิทินห้อง

ดูตารางการใช้ห้องรายวัน รายสัปดาห์ หรือรายเดือน เพื่อหาช่วงที่ว่าง

visible to: ROLE-001 (ผู้ใช้งานทั่วไป (General User)), ROLE-002 (ผู้ดูแลระบบห้องประชุม (Room Administrator)), ROLE-003 (ผู้ดูแลระบบไอที (System Administrator))

ช่วงเวลาที่ถูกจอง *
[เริ่ม, จบ) ของการจองที่ไม่ใช่ CANCELLED/REJECTED (ENT-007.startAt)
หัวข้อ
แสดงเฉพาะการจองที่ผู้ดูเป็นผู้จองหรือผู้เข้าร่วม ไม่งั้นแสดง 'ไม่ว่าง' (ENT-007.title)
ผู้จอง
แสดงเฉพาะการจองที่ผู้ดูเป็นผู้จองหรือผู้เข้าร่วม (ENT-007.bookedBy)
ผู้เข้าร่วม
แสดงเฉพาะการจองที่ผู้ดูเป็นผู้จองหรือผู้เข้าร่วม (ENT-008.user)

states

empty
ช่วงที่ดูไม่มีการจอง — ปฏิทินแสดงว่างทั้งหมดและเลือกช่วงเพื่อจองได้
loading
แสดงโครงปฏิทินพร้อมตัวบอกกำลังโหลด · เป้าโหลดเสร็จ ≤ 2 วินาที (NFR-mrr-002)
error
โหลดไม่สำเร็จ — แจ้งข้อผิดพลาดและปุ่มโหลดใหม่
unauthorized
การจองของคนอื่นแสดงเพียง 'ไม่ว่าง' ไม่มีรายละเอียด · ผู้ที่ยังไม่เข้าสู่ระบบถูกพาไปหน้าขอรหัสเข้าสู่ระบบ
overflow
หลายการจองในช่องเดียวของมุมมองรายเดือน — แสดง 3 รายการแรกและ '+N' ที่กดดูทั้งหมดได้
