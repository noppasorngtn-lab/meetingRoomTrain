## 3 · ห้าสถานะ

| สถานะ | เกิดกับหน้านี้ไหม | ข้อความที่ต้องแสดง |
|---|---|---|
| `empty` | เกิด | ฟอร์มเปิดพร้อมห้องและช่วงเวลาที่เลือกมา ช่องอื่นว่าง |
| `loading` | เกิด | ปุ่มยืนยันถูกปิดระหว่างบันทึกและส่ง Email |
| `error` | เกิด | ช่วงเวลาไม่ว่าง — แสดง 'ห้องนี้ไม่ว่างในช่วงเวลาที่เลือก กรุณาเลือกเวลาอื่น' · ห้องปิดปรับปรุง — แสดง 'ห้องนี้ปิดปรับปรุง ไม่สามารถจองได้' · ส่ง Email ไม่สำเร็จ — แจ้งให้กดใหม่ ข้อมูลในฟอร์มคงไว้ |
| `unauthorized` | เกิด | ผู้ที่ยังไม่เข้าสู่ระบบถูกพาไปหน้าขอรหัสเข้าสู่ระบบ |
| `overflow` | เกิด | หัวข้อเกิน 200 ตัวอักษรไม่รับ · ผู้เข้าร่วมเกินความจุห้อง — แสดงคำเตือนแต่ยังบันทึกได้ (req ไม่มีกฎห้าม) |

_ข้อความในตารางนี้คัดมาคำต่อคำจากที่ design ประกาศไว้ **ห้ามเขียนใหม่ให้สวยขึ้น**_

## 4 · กติกา UI ที่บังคับ

- **UIC-001** — ปุ่มประจำแถวอยู่คอลัมน์แรกของแถว เรียงลำดับตายตัว: view · edit · delete · manage · command
  - ใช้กับ: ทุกหน้าที่แสดงเป็นรายการแถว — ปุ่มประจำแถวทุกปุ่ม (ชนิด view · edit · delete · manage · command — ชนิดเป็นของ design ตั้งแต่ประตู 35)
- **UIC-002** — แสดงเป็นปุ่มตัวหนังสือ ไม่ใช่ไอคอน ใช้ชื่อ action ที่ design ประกาศไว้ใน actions[].name เป็นข้อความบนปุ่มและเป็นชื่อสำหรับ screen reader — ตาม design system mrr ที่กำหนดว่าปุ่มทุกปุ่มต้องมีข้อความ ไม่มีปุ่มไอคอนอย่างเดียว
  - ใช้กับ: ปุ่มประจำแถวทุกปุ่ม
- **UIC-003** — เปิดเป็น modal ทับรายการ ไม่พาไปหน้ารายละเอียดแยก
  - ใช้กับ: ปุ่มประจำแถวชนิด view
