# EX-mrr-141

## กำหนดให้ (given)
การจองห้อง A 17/10 10:00–11:00 หัวข้อ 'ประชุมทีม' ของ U1 ผู้เข้าร่วม U2 และ U3 (ยังไม่ถึงเวลาเริ่ม) · mail server ปฏิเสธ Email ถึง U3 เท่านั้น (ผู้รับคนอื่นรับได้)

## เมื่อ (when)
U1 ยกเลิกการจองนี้

## แล้ว (then)
การจองยังอยู่ สถานะเดิม และแสดงข้อความ 'ส่ง Email แจ้งเตือนไม่สำเร็จ กรุณากดใหม่อีกครั้ง'

## พิสูจน์กฎ

- [BR-mrr-019@v1](../rules/BR-mrr-019@v1.md) ✅ ปัจจุบัน — ถ้าส่ง Email แจ้งเตือนไม่สำเร็จ การกระทำของผู้ใช้ที่ทำให้เกิดแจ้งเตือนนั้นล้มทันที และแจ้งผู้ใช้ให้กดใหม่ — ไม่มีคิวส่งซ้ำ
