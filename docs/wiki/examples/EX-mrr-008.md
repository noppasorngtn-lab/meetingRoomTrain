# EX-mrr-008

## กำหนดให้ (given)
U1 เป็นผู้จองห้อง A พรุ่งนี้ 10:00–11:00 หัวข้อ 'ประชุมทีม' (ยังไม่ถึงเวลาเริ่ม)

U1 แก้หัวข้อเป็น 'ประชุมวางแผน' แล้วกดบันทึก

## แล้ว (then)
ระบบบันทึกการแก้ไข และแสดงข้อความ 'บันทึกการแก้ไขสำเร็จ'
