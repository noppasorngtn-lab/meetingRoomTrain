# EX-mrr-087

## กำหนดให้ (given)
ห้อง E ปิดปรับปรุงทุกวัน จ.–ศ. ตลอด ต.ค. 2569 · มีการจองที่คงอยู่ 5/10 10:00–11:00

## เมื่อ (when)
Room Administrator เปิดรายงานการใช้ห้องเดือน ต.ค. 2569

## แล้ว (then)
ห้อง E แสดง '—' ไม่มีเลขอันดับ และไม่อยู่ในอันดับห้องที่มีอัตราการใช้งานสูงสุด — ชั่วโมงทำการเหลือ 0 จึงไม่คำนวณ

## พิสูจน์กฎ

- [BR-mrr-006@v1](../rules/BR-mrr-006@v1.md) ❄️ — อัตราการใช้งานรายห้อง = ชั่วโมงที่ถูกจองและใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว — ไม่นับยกเลิก / ปฏิเสธ / รออนุมัติ) ÷ ชั่วโมงทำการของห้องในช่วงรายงาน · ปัดทุกจุดแบบ round half up · ใช้จัดอันดับห้องที่ใช้งานสูงสุด
- [BR-mrr-006@v2](../rules/BR-mrr-006@v2.md) ✅ ปัจจุบัน — อัตราการใช้งานรายห้อง = ชั่วโมงที่ถูกจองและใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว — ไม่นับยกเลิก / ปฏิเสธ / รออนุมัติ) ÷ ชั่วโมงทำการของห้องในช่วงรายงาน · ปัดทุกจุดแบบ round half up · ใช้จัดอันดับห้องที่ใช้งานสูงสุด · ห้องที่อัตราการใช้งานเท่ากัน (เทียบหลังปัดตามสัญญาการคำนวณเหลือทศนิยม 2 ตำแหน่ง) ได้อันดับเดียวกัน และห้องถัดไปข้ามเลขอันดับ เช่น 1, 1, 3
