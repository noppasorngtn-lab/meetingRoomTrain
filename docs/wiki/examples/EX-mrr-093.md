# EX-mrr-093

## กำหนดให้ (given)
U1 กดขอรหัสตอน 10:00 แล้วเห็นข้อความ 'ส่งรหัสไม่สำเร็จ กรุณาลองใหม่อีกครั้ง' · mail server กลับมาทำงานตอน 10:05

## เมื่อ (when)
U1 ไม่ได้กดขอรหัสอีก จนถึง 10:30

## แล้ว (then)
U1 ไม่ได้รับ Email รหัสเข้าสู่ระบบเลย — ระบบไม่ส่งซ้ำให้เอง เพราะไม่มีคิวส่งซ้ำ

## พิสูจน์กฎ

- [BR-mrr-024@v1](../rules/BR-mrr-024@v1.md) ✅ ปัจจุบัน — ถ้าส่ง Email รหัสเข้าสู่ระบบไม่สำเร็จ การขอรหัสครั้งนั้นล้มทันที และแจ้งผู้ใช้ให้กดขอรหัสใหม่เอง — ไม่มีคิวส่งซ้ำ
