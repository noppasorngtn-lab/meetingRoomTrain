# EX-mrr-148

## กำหนดให้ (given)
U1 เข้าสู่ระบบอยู่ และเปิดหน้า 'ค้นหาห้องว่าง'

## เมื่อ (when)
U1 กด 'ออกจากระบบ'

## แล้ว (then)
ระบบยกเลิก session ของ U1 และแสดงหน้า 'ออกจากระบบแล้ว' พร้อมทางเข้าสู่ระบบอีกครั้ง · session เดิมใช้เปิดหน้าที่ต้องเข้าสู่ระบบไม่ได้อีก

## พิสูจน์กฎ

- [BR-mrr-029@v1](../rules/BR-mrr-029@v1.md) ✅ ปัจจุบัน — ผู้ใช้ออกจากระบบได้ทุกเมื่อ ระบบยกเลิก session และแสดงหน้า 'ออกจากระบบแล้ว' พร้อมทางเข้าสู่ระบบอีกครั้ง · ถ้ายกเลิก session ไม่สำเร็จ แจ้ง 'ออกจากระบบไม่สำเร็จ กรุณาลองอีกครั้ง' และยังไม่แสดงว่าออกแล้ว · ผู้ที่ยังไม่ได้เข้าสู่ระบบเปิดหน้าออกจากระบบ เห็นหน้าเดียวกับผู้ที่เพิ่งออก
