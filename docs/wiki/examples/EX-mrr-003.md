# EX-mrr-003

## กำหนดให้ (given)
ห้อง B (ต้องอนุมัติ) มีการจอง 09:00–10:00 สถานะรออนุมัติ

## เมื่อ (when)
ผู้ใช้อีกคนจองห้อง B เวลา 09:30–10:30

## แล้ว (then)
ระบบไม่รับการจอง และแสดงข้อความ 'ห้องนี้ไม่ว่างในช่วงเวลาที่เลือก กรุณาเลือกเวลาอื่น' — การจองที่รออนุมัติกันช่วงเวลาไว้

## พิสูจน์กฎ

- [BR-mrr-001@v1](../rules/BR-mrr-001@v1.md) ✅ ปัจจุบัน — ห้องเดียวกันห้ามมีการจองที่ช่วงเวลาทับกัน — ระบบตรวจสอบความพร้อมของห้องอัตโนมัติก่อนรับการจอง · ช่วงเวลานับแบบ [เริ่ม, จบ) การจองที่จบ 10:00 กับที่เริ่ม 10:00 ไม่นับว่าทับ จองต่อกันได้ · การจองที่รออนุมัตินับเป็นการจองที่กันช่วงเวลา จนกว่าจะถูกปฏิเสธหรือยกเลิก
