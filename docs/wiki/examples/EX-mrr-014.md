# EX-mrr-014

## กำหนดให้ (given)
การจองห้อง B พรุ่งนี้ 10:00–11:00 ของ U1 มีสถานะ 'รออนุมัติ' และ U1 เป็น General User

## เมื่อ (when)
U1 ส่งคำสั่งอนุมัติการจองของตัวเอง

## แล้ว (then)
สถานะยังเป็น 'รออนุมัติ' และแสดงข้อความ 'เฉพาะผู้ดูแลห้องเท่านั้นที่อนุมัติได้'

## พิสูจน์กฎ

- [BR-mrr-004@v1](../rules/BR-mrr-004@v1.md) ✅ ปัจจุบัน — การจองห้องที่ถูกตั้งไว้ว่า "ต้องอนุมัติ" จะใช้งานจริงได้ต่อเมื่อ Room Administrator อนุมัติแล้ว ห้องที่ไม่ได้ตั้งไว้ไม่ต้องรออนุมัติ
