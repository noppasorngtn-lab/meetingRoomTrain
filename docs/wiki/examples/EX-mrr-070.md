# EX-mrr-070

## กำหนดให้ (given)
ห้อง A มีการจอง 17/10 10:00–11:00 หัวข้อ 'ประชุมทีม' ของ U1 ผู้เข้าร่วม U2, U3 · ผู้ใช้ล็อกอินเป็น U4 (General User · ไม่ได้จองและไม่ได้เป็นผู้เข้าร่วม)

## เมื่อ (when)
U4 เปิดปฏิทินห้อง A วันที่ 17/10

## แล้ว (then)
ช่อง 10:00–11:00 ของห้อง A แสดงแค่คำว่า 'ไม่ว่าง' ไม่แสดงผู้จอง หัวข้อ หรือผู้เข้าร่วม

## พิสูจน์กฎ

- [BR-mrr-021@v1](../rules/BR-mrr-021@v1.md) ✅ ปัจจุบัน — ในปฏิทิน General User เห็นรายละเอียด (ผู้จอง · หัวข้อ · ผู้เข้าร่วม) เฉพาะการจองที่ตัวเองจองหรือเป็นผู้เข้าร่วม — การจองของคนอื่นเห็นแค่ว่าช่วงเวลานั้น "ไม่ว่าง"
