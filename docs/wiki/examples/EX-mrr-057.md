# EX-mrr-057

## กำหนดให้ (given)
การจองห้อง A 18/10 10:00–11:00 ของ U1 · ขณะนี้ 18/10 10:30 และผู้ใช้ล็อกอินเป็น RA1

## เมื่อ (when)
RA1 ยกเลิกการจองนี้แทน U1 โดยเว้นช่องเหตุผลว่าง แล้วเปิดดูร่องรอยของการจองนี้

## แล้ว (then)
การจองคงเดิม แสดงข้อความ 'กรุณาระบุเหตุผล' และร่องรอยของการจองนี้ไม่มีรายการใหม่ — การกระทำที่ไม่สำเร็จไม่บันทึกร่องรอย
