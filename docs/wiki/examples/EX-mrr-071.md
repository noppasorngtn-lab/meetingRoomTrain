# EX-mrr-071

## กำหนดให้ (given)
ห้อง B (ต้องอนุมัติ) มีการจอง 17/10 10:00–11:00 หัวข้อ 'ประชุมลูกค้า' ของ U1 สถานะ 'รออนุมัติ' ผู้เข้าร่วม U2 · ผู้ใช้ล็อกอินเป็น U4 (General User · ไม่เกี่ยวข้อง)

## เมื่อ (when)
U4 เปิดปฏิทินห้อง B วันที่ 17/10

## แล้ว (then)
ช่อง 10:00–11:00 ของห้อง B แสดงแค่คำว่า 'ไม่ว่าง' ไม่แสดงผู้จอง หัวข้อ ผู้เข้าร่วม หรือสถานะ 'รออนุมัติ'

## พิสูจน์กฎ

- [BR-mrr-021@v1](../rules/BR-mrr-021@v1.md) ✅ ปัจจุบัน — ในปฏิทิน General User เห็นรายละเอียด (ผู้จอง · หัวข้อ · ผู้เข้าร่วม) เฉพาะการจองที่ตัวเองจองหรือเป็นผู้เข้าร่วม — การจองของคนอื่นเห็นแค่ว่าช่วงเวลานั้น "ไม่ว่าง"
