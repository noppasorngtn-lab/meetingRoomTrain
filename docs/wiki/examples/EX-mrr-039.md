# EX-mrr-039

## กำหนดให้ (given)
ห้อง B ต้องอนุมัติ และกำหนดผู้อนุมัติประจำห้องเป็น RA1 · การจองห้อง B 18/10 10:00–11:00 ของ U1 มีสถานะ 'รออนุมัติ' · ผู้ใช้ล็อกอินเป็น RA1

## เมื่อ (when)
RA1 กดอนุมัติการจองนี้

## แล้ว (then)
การจองเปลี่ยนเป็นสถานะ 'อนุมัติแล้ว' และ RA1 เห็นข้อความ 'อนุมัติการจองสำเร็จ'

## พิสูจน์กฎ

- [BR-mrr-013@v1](../rules/BR-mrr-013@v1.md) ✅ ปัจจุบัน — แต่ละห้องที่ต้องอนุมัติกำหนดผู้อนุมัติประจำห้อง (Room Administrator) ได้ — ถ้ายังไม่กำหนด Room Administrator ทุกคนอนุมัติได้ และกำหนดทีหลังได้
