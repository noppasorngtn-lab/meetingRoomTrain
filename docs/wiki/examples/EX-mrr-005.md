# EX-mrr-005

## กำหนดให้ (given)
ห้อง A (ไม่ต้องอนุมัติ) ว่างช่วง 13:00–14:00

## เมื่อ (when)
ผู้ใช้จองห้อง A 13:00–14:00 หัวข้อ 'ประชุมทีม' ผู้เข้าร่วม 3 คน ไม่เลือกอุปกรณ์เสริม

## แล้ว (then)
ระบบรับการจอง และแสดงข้อความ 'จองห้องสำเร็จ' — อุปกรณ์เสริมไม่บังคับ

- [BR-mrr-002@v1](../rules/BR-mrr-002@v1.md) ✅ ปัจจุบัน — การจองต้องระบุหัวข้อการประชุมและรายชื่อผู้เข้าร่วม ส่วนอุปกรณ์เสริมเลือกหรือไม่เลือกก็ได้
