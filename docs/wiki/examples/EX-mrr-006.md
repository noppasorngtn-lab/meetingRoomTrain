# EX-mrr-006

## กำหนดให้ (given)
ห้อง A (ไม่ต้องอนุมัติ) ว่างช่วง 13:00–14:00

## เมื่อ (when)
ผู้ใช้จองห้อง A 13:00–14:00 โดยเว้นช่องหัวข้อการประชุมว่าง ผู้เข้าร่วม 3 คน

## แล้ว (then)
ระบบไม่รับการจอง และแสดงข้อความ 'กรุณาระบุหัวข้อการประชุม'

## พิสูจน์กฎ

- [BR-mrr-002@v1](../rules/BR-mrr-002@v1.md) ✅ ปัจจุบัน — การจองต้องระบุหัวข้อการประชุมและรายชื่อผู้เข้าร่วม ส่วนอุปกรณ์เสริมเลือกหรือไม่เลือกก็ได้
