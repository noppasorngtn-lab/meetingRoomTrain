## เนื้อความ

> QB-int-01: ส่ง Email รหัสเข้าสู่ระบบ (OTP) ไม่สำเร็จ (mail server ล่ม) — ล้มทันที แจ้งผู้ใช้ให้กดขอรหัสใหม่เอง · เป็นคนละกฎกับ BR-mrr-019 เพราะรหัสเข้าสู่ระบบไม่ใช่การแจ้งเตือน QB-idem-01: ผู้ใช้กดขอรหัสซ้ำ (กดรัว ๆ หรือกดขอรหัสใหม่) — กันการขอซ้ำแล้วแจ้ง error ห้ามขอรหัสใหม่ระหว่างที่รหัสเดิมยังใช้ได้ QB-perm-02: เข้าสู่ระบบได้เฉพาะพนักงานที่อยู่ในรายชื่อนำเข้าจาก HR และบัญชี active — ถ้าไม่เข้าเงื่อนไข ระบบตอบข้อความเดียวกับกรณีปกติแต่ไม่ส่งรหัส และเข้าสู่ระบบไม่ได้ กฎการเข้าสู่ระบบอยู่ใต้ REQ-mrr-001 (ที่ NFR-mrr-001 อยู่) — รอบนี้ถามเพื่อปิดการ์ด GAP-mrr-003 ที่ dev ยกขึ้นมา (UC-mrr-020 ไม่มีเกณฑ์รับ)
