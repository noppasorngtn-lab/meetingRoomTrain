# DQ-mrr-003

## คำถามที่เลื่อนไป
ข้อมูลห้องต้อง soft-delete / archive ไหม — §3.2 เขียนว่า "ลบข้อมูลห้องประชุม" แต่ DQ-mrr-001 ตอบว่าห้ามลบ ต้องตกลงว่า "ลบ" หมายถึงอะไร

## คำตอบ
ลบ = archive — ห้องเข้าสถานะ ARCHIVED (เลิกใช้งาน) ถาวร ไม่แสดงให้ค้นหาหรือจอง ข้อมูลและการจองเดิมคงไว้ เปิดกลับไม่ได้
