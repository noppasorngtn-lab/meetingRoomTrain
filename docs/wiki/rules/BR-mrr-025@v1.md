# BR-mrr-025@v1

## ข้อความของกฎ
ระหว่างที่รหัสเข้าสู่ระบบที่ส่งไปแล้วยังใช้ได้ ผู้ใช้คนเดิมขอรหัสใหม่ไม่ได้ — ระบบกันการขอซ้ำ แจ้ง error และไม่ออกรหัสใหม่

## ที่มา

> "QB-idem-01: ผู้ใช้กดขอรหัสซ้ำ (กดรัว ๆ หรือกดขอรหัสใหม่) — กันการขอซ้ำแล้วแจ้ง error ห้ามขอรหัสใหม่ระหว่างที่รหัสเดิมยังใช้ได้"
