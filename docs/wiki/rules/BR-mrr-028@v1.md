# BR-mrr-028@v1

## ข้อความของกฎ
รหัสที่ผิด หมดอายุ หรือถูกใช้ไปแล้ว เข้าสู่ระบบไม่ได้ — ระบบไม่สร้าง session และแจ้งเหตุ · กรอกผิดไม่ทำให้รหัสเสีย ผู้ใช้กรอกใหม่ด้วยรหัสเดิมได้จนหมดอายุ

## ที่มา

> "รหัสหนึ่งตัวใช้ได้ครั้งเดียว — รหัสผิด หมดอายุ หรือถูกใช้ไปแล้ว ระบบไม่สร้าง session และแจ้งเหตุ"
> — [SRC-027](../sources/SRC-027.md) หน้า — §—

> "กรอกรหัสผิดระหว่างที่รหัสยังไม่หมดอายุ — กรอกใหม่ด้วยรหัสเดิมได้จนหมดอายุ รหัสไม่เสียเพราะกรอกผิด · ขอรหัสใหม่ได้เมื่อรหัสเดิมหมดอายุหรือถูกใช้ไปแล้ว (ยืนยัน BR-mrr-025)"
> — [SRC-027](../sources/SRC-027.md) หน้า — §—
