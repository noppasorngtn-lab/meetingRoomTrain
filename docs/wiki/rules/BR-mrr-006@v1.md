# BR-mrr-006@v1

## ข้อความของกฎ
อัตราการใช้งานรายห้อง = ชั่วโมงที่ถูกจองและใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว — ไม่นับยกเลิก / ปฏิเสธ / รออนุมัติ) ÷ ชั่วโมงทำการของห้องในช่วงรายงาน · ปัดทุกจุดแบบ round half up · ใช้จัดอันดับห้องที่ใช้งานสูงสุด

คำนวณตามสัญญา [CALC-mrr-001@v1](../calculations/CALC-mrr-001@v1.md)

## ที่มา

> "สถิติห้องที่มีอัตราการใช้งานสูงสุด (Utilization Rate) เพื่อนำไปวางแผนทรัพยากร"
> — [SRC-001](../sources/SRC-001.md) หน้า — §3.2

> "อัตราการใช้งานของห้อง = ชั่วโมงที่ถูกจอง ÷ ชั่วโมงทำการของห้อง"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

> "นับเฉพาะการจองที่ใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว) — ไม่นับที่ยกเลิก / ปฏิเสธ / รออนุมัติ"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

> "QB-calc-01: ผลที่มีเศษทศนิยม ปัดทุกจุดแบบ round half up"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

- [EX-mrr-085](../examples/EX-mrr-085.md) — boundary: ห้อง C แสดง '0.45%' — นับเฉพาะ 17:00–18:00 ของวันศุกร์ (60 นาที) ส่วนหลัง 18:00 และวันเสาร์ไม่นับ · 60 ÷ 13,200 × 100 = 0.4545… ปัดเป็น 0.45
- [EX-mrr-086](../examples/EX-mrr-086.md) — alternate: ห้อง D แสดง '50.00%' — ตัวหารเหลือ 13,200 − 3,000 = 10,200 นาที และการจอง 21/10 ที่อยู่ในช่วงปิดปรับปรุงไม่นับในตัวตั้ง
