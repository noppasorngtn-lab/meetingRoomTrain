# BR-mrr-029@v1

## ข้อความของกฎ
ผู้ใช้ออกจากระบบได้ทุกเมื่อ ระบบยกเลิก session และแสดงหน้า 'ออกจากระบบแล้ว' พร้อมทางเข้าสู่ระบบอีกครั้ง · ถ้ายกเลิก session ไม่สำเร็จ แจ้ง 'ออกจากระบบไม่สำเร็จ กรุณาลองอีกครั้ง' และยังไม่แสดงว่าออกแล้ว · ผู้ที่ยังไม่ได้เข้าสู่ระบบเปิดหน้าออกจากระบบ เห็นหน้าเดียวกับผู้ที่เพิ่งออก

## พิสูจน์โดย

- [EX-mrr-148](../examples/EX-mrr-148.md) — happy: ระบบยกเลิก session ของ U1 และแสดงหน้า 'ออกจากระบบแล้ว' พร้อมทางเข้าสู่ระบบอีกครั้ง · session เดิมใช้เปิดหน้าที่ต้องเข้าสู่ระบบไม่ได้อีก
- [EX-mrr-149](../examples/EX-mrr-149.md) — exception: แสดงข้อความ 'ออกจากระบบไม่สำเร็จ กรุณาลองอีกครั้ง' · ไม่แสดงหน้า 'ออกจากระบบแล้ว' และ U1 ยังเข้าสู่ระบบอยู่
- [EX-mrr-150](../examples/EX-mrr-150.md) — boundary: แสดงหน้า 'ออกจากระบบแล้ว' พร้อมทางเข้าสู่ระบบอีกครั้ง เหมือนกับผู้ที่เพิ่งออกจากระบบ — ไม่แสดง error
