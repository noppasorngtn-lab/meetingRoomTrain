# BR-mrr-006@v2

## ข้อความของกฎ
อัตราการใช้งานรายห้อง = ชั่วโมงที่ถูกจองและใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว — ไม่นับยกเลิก / ปฏิเสธ / รออนุมัติ) ÷ ชั่วโมงทำการของห้องในช่วงรายงาน · ปัดทุกจุดแบบ round half up · ใช้จัดอันดับห้องที่ใช้งานสูงสุด · ห้องที่อัตราการใช้งานเท่ากัน (เทียบหลังปัดตามสัญญาการคำนวณเหลือทศนิยม 2 ตำแหน่ง) ได้อันดับเดียวกัน และห้องถัดไปข้ามเลขอันดับ เช่น 1, 1, 3

คำนวณตามสัญญา [CALC-mrr-001@v1](../calculations/CALC-mrr-001@v1.md)

## ที่มา

> "สถิติห้องที่มีอัตราการใช้งานสูงสุด (Utilization Rate) เพื่อนำไปวางแผนทรัพยากร"
> — [SRC-001](../sources/SRC-001.md) หน้า — §3.2

> "อัตราการใช้งานของห้อง = ชั่วโมงที่ถูกจอง ÷ ชั่วโมงทำการของห้อง"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

> "นับเฉพาะการจองที่ใช้ได้จริง (ไม่ต้องอนุมัติ หรืออนุมัติแล้ว) — ไม่นับที่ยกเลิก / ปฏิเสธ / รออนุมัติ"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

> "QB-calc-01: ผลที่มีเศษทศนิยม ปัดทุกจุดแบบ round half up"
> — [SRC-012](../sources/SRC-012.md) หน้า — §—

> "เมื่อห้องตั้งแต่สองห้องขึ้นไปมีอัตราการใช้งาน ... เท่ากัน จะจัดอันดับอย่างไร"
> — [SRC-032](../sources/SRC-032.md) หน้า — §—

> "ห้องที่อัตราการใช้งานเท่ากันให้ อันดับเท่ากัน (competition ranking ... เช่น 1, 1, 3)"
> — [SRC-033](../sources/SRC-033.md) หน้า — §—

## พิสูจน์โดย

- [EX-mrr-084](../examples/EX-mrr-084.md) — happy: อันดับ 1 ห้อง B '66.67%' · อันดับ 2 ห้อง A '33.33%' — การจองที่ยกเลิก / รออนุมัติ / ถูกปฏิเสธไม่นับ และ 66.666… ปัดแบบ round half up เป็น 66.67
- [EX-mrr-085](../examples/EX-mrr-085.md) — boundary: ห้อง C แสดง '0.45%' — นับเฉพาะ 17:00–18:00 ของวันศุกร์ (60 นาที) ส่วนหลัง 18:00 และวันเสาร์ไม่นับ · 60 ÷ 13,200 × 100 = 0.4545… ปัดเป็น 0.45
- [EX-mrr-086](../examples/EX-mrr-086.md) — alternate: ห้อง D แสดง '50.00%' — ตัวหารเหลือ 13,200 − 3,000 = 10,200 นาที และการจอง 21/10 ที่อยู่ในช่วงปิดปรับปรุงไม่นับในตัวตั้ง
- [EX-mrr-087](../examples/EX-mrr-087.md) — exception: ห้อง E แสดง '—' ไม่มีเลขอันดับ และไม่อยู่ในอันดับห้องที่มีอัตราการใช้งานสูงสุด — ชั่วโมงทำการเหลือ 0 จึงไม่คำนวณ
