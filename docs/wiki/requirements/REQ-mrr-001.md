# REQ-mrr-001

## เป้าหมาย
ค้นหาห้องว่าง ดูตารางการใช้ห้อง จองห้อง และจัดการการจองของตนเองได้ โดยไม่เกิดการจองซ้ำ — การจองห้องทุกครั้งต้องผ่านระบบ ไม่เหลือการจองนอกระบบ

**actor:** General User · **ความสำคัญ:** high · **มีหน้าจอ:** ใช่

## คุณค่าทางธุรกิจ
ลดความซ้ำซ้อนในการจอง และบริหารจัดการทรัพยากรห้องประชุมขององค์กรให้เกิดประโยชน์สูงสุด

## NFR

- [NFR-mrr-001](../nfr/NFR-mrr-001.md) — เข้าสู่ระบบด้วย Email ขององค์กรอย่างเดียว — ไม่เชื่อม Active Directory (SSO) ในรอบนี้ (SRC-010)
- [NFR-mrr-002](../nfr/NFR-mrr-002.md) — รองรับผู้ใช้งานพร้อมกัน 200 คน และหน้าจอตารางห้องประชุมโหลดเสร็จภายใน 2 วินาที (เอกสารเขียน "อย่างน้อย 100-200 คน" — เจ้าของเลือก 200 ดู Q-mrr-004)
- [NFR-mrr-003](../nfr/NFR-mrr-003.md) — เข้ารหัสข้อมูลการใช้งานผ่าน HTTPS และจำกัดสิทธิ์การเข้าถึงตามระดับผู้ใช้งาน (Role-Based Access Control)
- [NFR-mrr-004](../nfr/NFR-mrr-004.md) — เปิดให้บริการตลอด 24 ชั่วโมง (Uptime 99.9%)
- [NFR-mrr-005](../nfr/NFR-mrr-005.md) — รองรับ Chrome, Safari, Edge, Firefox และแสดงผลได้ดีบนอุปกรณ์เคลื่อนที่ (Responsive Design)
