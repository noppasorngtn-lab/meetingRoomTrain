# REQ-mrr-001

## เป้าหมาย
ค้นหาห้องว่าง ดูตารางการใช้ห้อง จองห้อง และจัดการการจองของตนเองได้ โดยไม่เกิดการจองซ้ำ — การจองห้องทุกครั้งต้องผ่านระบบ ไม่เหลือการจองนอกระบบ

**actor:** General User · **ความสำคัญ:** high · **มีหน้าจอ:** ใช่ · **สถานะ:** draft

## คุณค่าทางธุรกิจ
ลดความซ้ำซ้อนในการจอง และบริหารจัดการทรัพยากรห้องประชุมขององค์กรให้เกิดประโยชน์สูงสุด

## ความเป็นมา

**ข้อห้ามของ General User (ชั้น 1 รอบ B, SRC-003):** ไม่มีข้อห้ามเพิ่มเติม — ทำได้ทุกอย่างในขอบเขตการจองของตัวเอง · หมวด permission ชั้น 2 ยืนยันแล้วว่าตรงกับ BR-mrr-003 และเพิ่มจุดตัดเวลาเริ่มประชุมเป็น BR-mrr-009 (SRC-004)

**นอกขอบเขตรอบนี้:** การเข้าสู่ระบบผ่าน Active Directory (SSO) ที่ §3.1 เอ่ยถึง — รอบนี้ใช้ Email ขององค์กรอย่างเดียว (SRC-010)

- [NFR-mrr-003](../nfr/NFR-mrr-003.md) — เข้ารหัสข้อมูลการใช้งานผ่าน HTTPS และจำกัดสิทธิ์การเข้าถึงตามระดับผู้ใช้งาน (Role-Based Access Control)
- [NFR-mrr-004](../nfr/NFR-mrr-004.md) — เปิดให้บริการตลอด 24 ชั่วโมง (Uptime 99.9%) วัดรายเดือนจาก log ของระบบ ไม่นับช่วงบำรุงรักษาตามแผนเป็น downtime · ปิดบำรุงรักษาตามแผนต้องแจ้งล่วงหน้า 7 วันทำการ (แจ้งน้อยกว่านั้นก็ยังไม่นับเป็น downtime) (ค่าวัด: SRC-034, SRC-037)
- [NFR-mrr-005](../nfr/NFR-mrr-005.md) — รองรับ Chrome, Safari, Edge, Firefox และแสดงผลได้ดีบนอุปกรณ์เคลื่อนที่ (Responsive Design)
