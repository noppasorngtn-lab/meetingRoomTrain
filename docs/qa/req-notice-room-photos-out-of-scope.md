# แจ้ง req: รูปภาพห้องถูกตัดออกจากรอบนี้ (ADR-007)

**ถึง:** req / BA / PO · **จาก:** mock · **สถานะ:** แจ้งเพื่อทราบ + รอคำตอบ 2 ข้อ — ยังไม่ได้แก้อะไรใน spec (spec เป็นของ req)

## เรื่องที่เกิดขึ้น

ลูกค้า/BA ตัดสินผ่าน Noppasorn Y เมื่อ 2026-11-17 ว่า **รูปภาพห้อง (UI-mrr-013) ยังไม่อยู่ในขอบเขตรอบนี้**
design บันทึกเป็น ADR-007 ข้อ (3) แล้วตัดช่องรูปภาพออกจากฟอร์ม · mock วาด UI-mrr-013 ใหม่ (MCK-mrr-012, commit 995bea2) · dev ตัดจากโค้ดแล้ว (1a4f01b)

ADR-007 เองระบุว่า **นี่คือการลดขอบเขตเทียบกับที่ req อธิบายไว้ และ req ยังไม่ได้รับแจ้ง** — ไฟล์นี้คือการแจ้ง

## ที่ spec ของ req ยังพูดถึงรูปภาพอยู่ (ยังไม่แก้ — รอ req)

| ที่ | ข้อความ |
|---|---|
| `REQ-mrr-003` goal | "…พร้อมกำหนดความจุ **รูปภาพ** และสิ่งอำนวยความสะดวก" |
| `UL-mrr-001` ห้องประชุม (glossary) | "มีความจุ **รูปภาพ** และสิ่งอำนวยความสะดวกประจำห้อง" |
| rule ลำดับที่ 5 ใน spec (provenance ที่ 2) | อ้างคำพูดต้นทาง "…พร้อมกำหนดความจุและรูปภาพ" |

คำพูดต้นทาง (SRC) เป็นหลักฐานจริง ไม่ต้องแก้ · สิ่งที่ req ต้องตัดสินคือประโยคที่ req เขียนเอง (goal, definition)

## ที่ design ยังเก็บไว้ (เจตนา)

- `datamodel.json` ยังมีฟิลด์ `photos` (อาร์เรย์ file id ว่างได้) — ไม่ได้ลบ เพราะรอบหน้าจะกลับมาใช้ · ADR-006 ยังกำหนดว่ารูปภาพเห็นเฉพาะผู้ดูแลห้อง
- ผลคือ spec กับหน้าจอ **ไม่ตรงกัน** ชั่วคราว: ข้อมูลมี ฟอร์มไม่มีที่ใส่

## คำถามถึง req (คำถามละเรื่อง · ตัวเลือก (เสนอ) คือข้อเสนอของ mock ไม่ใช่คำตอบ)

### Q1 · ประโยคเรื่องรูปภาพใน REQ-mrr-003 และ UL-mrr-001
- A (เสนอ) คงข้อความไว้ และจดว่ารูปภาพ "เลื่อนไปรอบหน้า" — ขอบเขตเดิมของลูกค้ายังเป็นความจริง แค่ส่งมอบทีหลัง
- B แก้ goal/definition ให้ตัดรูปภาพออก — ถ้าลูกค้ายกเลิกถาวร
- ทางไหนก็ต้องเปิดใบเปลี่ยนแปลง (`/req:change`) เพราะเป็นการเปลี่ยนที่ req ต้องเซ็น

### Q2 · รอบหน้าเมื่อไหร่ และต้องมีตัวอย่าง (EX) เรื่องรูปภาพไหม
ตอนนี้ไม่มีกฎหรือ EX ที่พิสูจน์พฤติกรรมรูปภาพ (ชนิดไฟล์ ขนาดสูงสุด จำนวนรูป — GAP-mrr-016 ถามไว้แล้วและยังไม่มีคำตอบเชิงกฎ) · ถ้ารอบหน้าจะทำ ต้องมีคำตอบก่อน ไม่งั้น design เขียน AC เองไม่ได้

## ผลต่อ downstream ถ้าเลือก B

เปิด `/req:change` → design รับ change ผ่าน `/design:change` → mock รันฟอร์ม UI-mrr-013 ซ้ำ (ตอนนี้ไม่มีช่องรูปอยู่แล้ว จึงน่าจะไม่เปลี่ยนหน้า) → dev ลบฟิลด์ `photos` ถ้าจะตัดทิ้งจริง
