# คำตอบของ gaps ที่ถึง design / mock (dev gaps)

**ผู้ตัดสิน:** Noppasorn Y · **วันที่ตัดสิน:** 2026-11-17 · **ที่มา:** การ์ด `GAP-mrr-*` ใน `.aeon/dev/features.json`

## ทำไมคำตอบอยู่ในไฟล์นี้ ไม่ได้อยู่ที่โต๊ะ design

ผมบันทึกคำตอบ 5 ข้อด้วย `desk.mjs --gap <id> --raiser dev --as answer` ได้สำเร็จ แต่เกตของ design ตกทันที
(`S2` 5 error: `desk.json:cards[n].card: "GAP-mrr-014" — GAP- belongs to dev · qa`)
สาเหตุอยู่ที่ plugin `design`: `desk.mjs` เขียนคำตอบของการ์ด dev ไว้ที่ `cards[].card` (ประตู 125) แต่ `REFERENCE_POSITIONS` ใน `check.mjs`
ไม่ประกาศตำแหน่งนี้ (คอมเมนต์ในโค้ดบอกว่าตำแหน่งของ `GAP-` จะประกาศตอนสร้างครึ่งปลายน้ำ ซึ่งยังไม่ทำ)
ผมคืน `desk.json` แล้ว (เกตกลับเป็น PASS) และ**ไม่แก้ plugin เพื่อให้เกตเงียบ** — เป็นโค้ดกลางนอกโปรเจกต์นี้ และเป็นวิธีที่คอมเมนต์เดียวกันเตือนว่าไม่ควรทำ

ผลคือการ์ดเหล่านี้ยังเปิดอยู่ใน `features.json` (dev ปิดฝั่งตัวเองไม่ได้ เพราะ "การ์ดที่ถึง design ปิดได้จากโต๊ะของ design เท่านั้น") จนกว่า plugin จะแก้
ควรแจ้งเจ้าของ plugin `design`: *เพิ่ม reference position สำหรับ `desk.json:cards[].card` (allow: `GAP`)*

## GAP-mrr-013 · API-022 — ตัดสินแล้ว ทำที่ design แล้ว รอเซ็น

ตัดสินโดย Noppasorn Y (2026-11-17): ผู้ใช้ที่เข้าสู่ระบบทุกบทบาทอ่านข้อมูลห้องที่ไม่ใช่ ARCHIVED ได้ผ่าน API-022 และเห็น **ชื่อ · ความจุ · ต้องอนุมัติ · สถานะ · ผู้อนุมัติประจำห้อง** ส่วน **รูปภาพ** เห็นเฉพาะผู้ดูแลห้อง

ที่ทำใน `rbac.json` (ผ่าน ADR-006 · ปลดลายเซ็นด้วยใบนั้น · absorb แล้ว · เกต PASS):
- `ACL-039` ROLE-001 · resource `UC-mrr-003` · อ่านข้อมูลห้องประกอบการจอง
- `ACL-040` ROLE-003 · resource `UI-mrr-010` · อ่านข้อมูลห้องประกอบการดูร่องรอย
- กฎฟิลด์ `ENT-003.photos` → `visibleTo: [ROLE-002]`
- เส้น `API-022 governedByAcl ACL-039` และ `ACL-040`

ข้อสังเกตที่ผู้ตัดสินควรอ่านก่อนเซ็น (การตีความของ QA ไม่ใช่คำตัดสิน):
1. **resource ของ ACL-040** — ผู้ดูแลระบบไอทีจองห้องไม่ได้ จึงผูกแถวของ ROLE-003 กับหน้าจัดการการจอง (UI-mrr-010) ที่เห็นร่องรอยการจอง ไม่ใช่ UC-mrr-003 · ถ้าต้องการผูกที่อื่นให้แก้แถวนี้
2. **การ์ดบอกว่า UI-mrr-006 ต้องเรียก API-022** แต่ในกราฟ `UI-mrr-006 calls` มีแค่ API-002, 004, 005 — ผมไม่ได้เพิ่มเส้น `calls` เพราะเป็นของ `screens.json` (ลงนามแล้ว) การประกาศว่าหน้าจองเรียก API-022 ยังไม่ได้ทำ
3. **ผู้ดูแลห้อง (ROLE-002)** อ่านข้อมูลห้องผ่าน ACL-014 อยู่แล้ว ไม่ได้เพิ่มแถว
4. การ์ด GAP-mrr-013 ยังเปิดอยู่ใน `features.json` เหมือนการ์ดอื่น (โต๊ะ design บันทึกไม่ได้ ดูหัวข้อบนสุด)
