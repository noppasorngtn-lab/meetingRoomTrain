- **Severity:** High [Recommended] — เทียบ §3.3 "ส่ง Email เตือนซ้ำหรือไม่ส่ง = High" (ผู้รับไม่ได้เตือนแต่ระบบบันทึกว่าส่งแล้ว และไม่ส่งซ้ำตามกฎ) · ให้ PO ยืนยัน
- **Environment / Build:** โค้ดที่ commit `49e84b7` · probe ใช้ `apps/api/dist` (gitignored; ตรวจเฉพาะบรรทัด `sendMail` ว่าตรงกับ `src`) · nodemailer 6.10.1 · Node v24.19.0 · ยังไม่ได้รันกับ docker stack
- **Pre-condition / Test Data (สังเคราะห์):** SMTP fixture `test/fixtures/partial-reject-smtp.mjs` ปฏิเสธ RCPT ของ `u3@mrr.local` (รับ `u1@`, `u2@mrr.local`) · การจอง 17/10 10:00–11:00 ของ U1 ผู้เข้าร่วม U2, U3 (ตาม EX-mrr-112)

- **Impact:** ผู้เข้าร่วม (General User) ที่ SMTP ปฏิเสธไม่ได้รับอีเมลเตือนโดยไม่มีร่องรอยว่าส่งไม่สำเร็จ · รายงาน/ข้อมูลสถานะเตือนของการจองบอกว่าส่งสำเร็จ · ไม่กระทบการจองหรือสิทธิ์

- **Open Questions:** (1) PO ยืนยัน defect และ Severity · (2) ขอบเขตผลต่อเหตุการณ์อื่นที่ใช้ transport เดียวกัน · (3) Dev ยืนยัน E2E หลังทำ fixture
