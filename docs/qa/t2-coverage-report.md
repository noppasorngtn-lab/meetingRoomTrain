## 5. NFR-mrr-005 — สิ่งที่ทำ

NFR ไม่ระบุเกณฑ์ที่วัดได้ (ช่อง "พิสูจน์ด้วย" ว่าง) **[TBD · ให้ PO ยืนยัน]** จึงนิยามเกณฑ์ปฏิบัติ [Recommended] 3 ข้อ:

2. ฟอร์มจองทำงานในเอนจินนั้น: ช่องวันเวลารับค่า, เลือกผู้เข้าร่วมได้, validation แสดง, คำขอส่งเวลาเป็น `+07:00`
3. บนอุปกรณ์สัมผัส ปุ่มยืนยัน/ยกเลิกกดได้ (≥ 24×24 CSS px ตาม WCAG 2.2 · 2.5.8 AA) และอยู่ในจอ

ไฟล์: `test/e2e/nfr-005-browsers.spec.ts` + projects ใน `test/playwright.config.ts`
(chromium, firefox, webkit-safari, edge, mobile-chrome=Pixel 7, mobile-safari=iPhone 14) — **ไม่เขียนข้อมูลลงฐานข้อมูล**

ผล: ทุก project ผ่าน (6–7 เคสต่อ project, 4 เคสอุปกรณ์สัมผัสข้ามบนเดสก์ท็อปโดยออกแบบ)
