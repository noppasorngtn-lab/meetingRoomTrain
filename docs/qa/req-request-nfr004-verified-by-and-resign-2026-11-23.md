2. **ความสม่ำเสมอ:** ตัดสินว่า NFR-001/003/005 ที่มีเคสแล้วแต่ `verified_by` ว่าง จะบันทึกด้วยหรือไม่ และคำศัพท์ชุดเดียวกันคืออะไร
