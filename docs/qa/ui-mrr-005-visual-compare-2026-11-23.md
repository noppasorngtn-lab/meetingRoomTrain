## ช่องวันที่ — ตอบแล้ว (ผู้ใช้ 2026-11-23)

**"วัน/เดือน/ปี" ต้องบังคับทุกเครื่อง ไม่ขึ้นกับภาษาของเครื่องผู้ใช้**

- design (`screens.json` UI-mrr-005 `date`) เขียนไว้แล้วว่า "วันที่ในรูปแบบวัน/เดือน/ปี" — คำตอบนี้ยืนยันว่าหมายถึงทุกเครื่อง · ไม่ต้องแก้ design
- แอปใช้ `<input type="date">` (`apps/web/src/features/calendar/CalendarPage.tsx:119`) ซึ่งเบราว์เซอร์แสดงตามภาษาเครื่อง จึงไม่ตรง · ต้องเป็นงานแก้ของ Dev
- **คำตอบเพิ่ม (ผู้ใช้ 2026-11-23):**
  1. ปีเป็น **พ.ศ.**
  2. **ใช้กฎเดียวกัน**กับช่องวันที่/เวลาหน้าอื่น: UI-mrr-004 `date` (`type="date"`) · UI-mrr-004 `start`/`end` (`type="time"`) · UI-mrr-006/008 `start`/`end` (`type="datetime-local"`)
- design ระบุ "วัน/เดือน/ปี" ไว้เฉพาะ UI-mrr-005 และไม่ได้ระบุ พ.ศ. ที่ไหนเลย · ช่องของหน้าอื่นไม่ได้ระบุรูปแบบ → **ต้องแก้ design ก่อน** แล้ว mock กับ Dev จึงตามได้ (ยังไม่ได้ทำ)
