## ช่องวันที่ — ตอบแล้ว (ผู้ใช้ 2026-11-23)

- design (`screens.json` UI-mrr-005 `date`) เขียนไว้แล้วว่า "วันที่ในรูปแบบวัน/เดือน/ปี" — คำตอบนี้ยืนยันว่าหมายถึงทุกเครื่อง · ไม่ต้องแก้ design
- แอปใช้ `<input type="date">` (`apps/web/src/features/calendar/CalendarPage.tsx:119`) ซึ่งเบราว์เซอร์แสดงตามภาษาเครื่อง จึงไม่ตรง · ต้องเป็นงานแก้ของ Dev
- **คำตอบเพิ่ม (ผู้ใช้ 2026-11-23):**
  1. ปีเป็น **ค.ศ.** (ตอบครั้งแรกว่า พ.ศ. แล้วเปลี่ยนเป็น ค.ศ. ในวันเดียวกัน)
